# Network Tool

أداة CLI بلغة Python لتحليل عناوين IP، حساب الـ Subnets، وفحص الشبكة.

## Features
- IP Information (Private/Global/Loopback/Reserved)
- Subnet & Host Calculations
- Public IP Lookup (Location, ISP, Time Zone)
- Multithreaded Ping Sweep
- Cross-Platform (Windows, Linux, macOS)

## Usage
\`\`\`bash
python scanner.py
\`\`\`
